# KSH Hosur Park Certifications

## Required Files

Place your three certification PDFs here and create a RAR archive named `ksh-certifications.rar`.

The RAR file should contain:
- Certificate 1 (PDF)
- Certificate 2 (PDF)
- Certificate 3 (PDF)

## How to Create the RAR File

1. Gather all three PDF certifications for KSH Hosur Park I
2. Use WinRAR or 7-Zip to create an archive named `ksh-certifications.rar`
3. Place the RAR file in this directory: `/public/certifications/ksh-certifications.rar`

## Download Link

Users will download the file from: `https://www.kshinfra.com/certifications/ksh-certifications.rar`
